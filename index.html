Настройки
ИИ-помощник (необязательно)
Без ИИ работают голосовые команды: «сколько топлива», «на сколько хватит», «температура», «наддув», «напряжение», «ошибки», «поехали на …». ИИ нужен только для свободных вопросов.
Ключ бесплатно: aistudio.google.com → Get API key, без карты. На бесплатном тарифе Google может использовать запросы для обучения.
Получить ключ: console.anthropic.com → API Keys.
Ключи хранятся только на этом устройстве.
Журнал обмена
Адаптер: ELM327 по обычному Bluetooth (сначала спарь его в настройках телефона, PIN 1234 или 0000) — кнопка «Подключить сканер»; BLE-адаптеры — отдельной кнопкой. Протокол: CAN 11 бит 500 кбит. Двигатель читается по стандартному OBD-II, приборка и остальные блоки VW — по протоколу VW TP2.0/KWP2000. Если что-то не читается — пришли журнал обмена, разберёмся.
